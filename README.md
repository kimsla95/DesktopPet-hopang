# DesktopPet 관리 설명서

바탕화면 펫 프로그램을 **수정하고 새 버전을 배포하는 방법**을 정리한 문서입니다.
명령어를 외울 필요 없이, 아래 순서대로 파일을 더블클릭하거나 Cursor에 부탁하면 됩니다.

---

## 1. 처음 한 번만 준비

1. **Inno Setup 설치** (설치 파일을 만드는 도구)
   - https://jrsoftware.org/isdl.php 에서 내려받아 설치하거나, Cursor에 "Inno Setup 설치해줘"라고 요청하세요.
2. **GitHub 공개 저장소 만들기**
   - https://github.com/new 에서 저장소를 만들고 **Public(공개)** 으로 설정합니다. (예: `내아이디/desktop-pet`)
3. **`version.json`에 저장소 주소 적기** ← 꼭 첫 배포 전에!
   ```json
   {
     "version": "1.0.0",
     "repo": "내아이디/desktop-pet"
   }
   ```
   이 주소가 프로그램 안에 함께 들어가야 사용자 프로그램이 업데이트를 확인할 수 있습니다.
   비어 있는 상태로 배포하면 그 버전은 업데이트 알림을 받지 못합니다.
4. (선택) **GitHub CLI 설치 + 로그인** – 설치하면 GitHub 업로드까지 자동으로 됩니다.
   Cursor에 "gh 설치하고 로그인 도와줘"라고 요청하세요.

---

## 2. 새 버전 배포하기 (매번)

| 순서 | 할 일 | 방법 |
|---|---|---|
| 1 | 프로그램 수정 | Cursor에 원하는 변경을 요청 |
| 2 | 업데이트 설명 작성 | `release_notes.md` 파일 내용을 이번 변경 내용으로 바꾸기 |
| 3 | 빌드 + 설치 파일 만들기 | `release.bat` 더블클릭 → 새 버전 번호 입력 (예: `1.0.1`) |
| 4 | GitHub에 올리기 | 자동 업로드(gh 설치 시) 또는 아래 "GitHub에 올리기" |

`release_notes.md` 예시 (이 내용이 사용자 업데이트 팝업에 그대로 보입니다):
```markdown
- 캐릭터 이동 기능 개선
- 알림 오류 수정
- 새로운 응원 메시지 추가
```

`release.bat`이 끝나면 `release` 폴더에 두 파일이 생깁니다.
- `DesktopPet-Setup-1.0.1.exe` : 설치/업데이트 파일
- `DesktopPet-Setup-1.0.1.exe.sha256` : 파일이 손상·변조되지 않았는지 확인하는 체크섬

### GitHub에 올리기 (웹사이트에서 직접)

1. GitHub 저장소 페이지 → 오른쪽 **Releases** → **Draft a new release**
2. **Choose a tag** 에 `v1.0.1` 입력 → *Create new tag*
3. 제목: `v1.0.1`, 설명: `release_notes.md` 내용 붙여넣기
4. `release` 폴더의 **두 파일**(`.exe`, `.exe.sha256`)을 끌어다 놓기
5. *Set as a pre-release* 는 체크하지 말고 **Publish release**

끝입니다. 사용자 프로그램이 다음 확인 때 새 버전을 알려줍니다.

---

## 3. 버전 번호 규칙

`주.부.수` 형식입니다. 항상 **이전보다 큰 번호**를 써야 업데이트 알림이 뜹니다.

| 예 | 언제 |
|---|---|
| 1.0.0 → 1.0.1 | 오류 수정 |
| 1.0.1 → 1.1.0 | 기능 추가 |
| 1.1.0 → 2.0.0 | 큰 변경 |

## 4. 사용자 쪽에서는 이렇게 동작해요

- 처음: GitHub Release 페이지에서 `DesktopPet-Setup-x.y.z.exe`를 받아 실행 → 설치 (관리자 권한 불필요)
  - 서명되지 않은 프로그램이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르면 됩니다.
- 실행 5초 뒤 백그라운드에서 새 버전 확인 (기본 6시간에 한 번, 설정에서 변경 가능)
- 새 버전이 있으면 팝업 → **지금 업데이트** 또는 **나중에**
- 지금 업데이트: 다운로드 → SHA256 검증 → 설치 프로그램 실행 → 펫 종료 → 설치 → 새 버전 자동 실행
- 인터넷이 없거나 실패해도 기존 프로그램은 그대로 사용 가능 (오류 팝업 반복 없음, 1시간 뒤 조용히 재시도)
- 설정(위치, 알림, 방목 등)은 `%APPDATA%\DesktopPet\settings.json`에 있어 업데이트·삭제 시에도 보존됩니다.
- 우클릭 → 알림 설정 → **업데이트** 칸: 현재 버전 표시, 자동 확인 켜기/끄기, 확인 주기, 지금 확인

## 5. 폴더 안내

| 경로 | 내용 |
|---|---|
| `version.json` | 현재 버전 + GitHub 저장소 주소 |
| `release_notes.md` | 이번 버전 업데이트 설명 |
| `release.bat` | 배포 파일 만들기 (빌드 + 설치 파일 + 체크섬 + 업로드) |
| `build.bat` | 프로그램만 빌드 (`dist\DesktopPet\DesktopPet.exe`) – 테스트용 |
| `pet/` | 프로그램 코드 |
| `assets/characters/` | 캐릭터 이미지와 대사 (`config.json`) |
| `installer/DesktopPet.iss` | 설치 프로그램 설정 |
| `tools/` | 배포 스크립트, 테스트 (`smoke_test.py`, `update_test.py`) |

---

## 6. 문제가 생기면

- `release.bat` 창에 `[실패]`가 보이면, 창의 내용을 복사해 Cursor에 붙여넣고 "고쳐줘"라고 요청하세요.
- 업데이트 알림이 안 뜰 때 확인할 것:
  1. `version.json`의 `repo`가 올바른가 (그 버전을 빌드할 때 들어 있었는가)
  2. GitHub Release가 **Publish** 되었고 pre-release가 아닌가
  3. 태그 번호(`v1.0.1`)가 설치된 버전보다 큰가
  4. 두 파일(`.exe`, `.exe.sha256`)이 모두 첨부되었는가
